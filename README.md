# LocalRun 🏃 — run a city, not just a distance

A running-route app for **orienting yourself in a new city**. Enter where you're
staying, pick how far you want to run and whether you want a loop or a one-way line,
and it builds a route threaded through the things that give you a first feel for the
place: waterfronts, greenways, parks, landmarks, viewpoints, and distinct
neighborhoods — the routes a local would actually pick. Then it runs with you:
live tracking, splits, turn-by-turn directions, and spoken call-outs for the
places you pass.

Cities: **New York, San Francisco, Boston, Chicago, Austin, Miami, London, Paris,
Tokyo.**

## Stack

- **Expo (React Native)** — runs in **Expo Go**, no native build needed
- **Map UI:** `react-native-maps` (Apple Maps on iOS)
- **Routing brain:** **Mapbox Directions + Map Matching + Geocoding** REST APIs
- **Curation:** per-city scenic datasets in `src/data/cities/`, generated by the
  `pipeline/` scripts (OSM + Wikipedia cross-reference), assembled into a
  distance-budgeted scenic route by `src/lib/routeBuilder.js`

## Setup

1. Install deps:
   ```bash
   npm install
   ```
2. Get a **free** Mapbox token: https://account.mapbox.com/access-tokens/
   Copy the default public token (starts with `pk.`).
3. Create your env file:
   ```bash
   cp .env.example .env
   # then paste your token into .env as EXPO_PUBLIC_MAPBOX_TOKEN
   ```
4. Start with a cleared cache (required after editing `.env`):
   ```bash
   npx expo start -c
   ```
5. Open **Expo Go** on your phone and scan the QR code.

> Without a token the app still loads, but route-building and address search are
> disabled (you'll see a warning on the plan screen).

## How it works

**Plan screen** — pick a city (or let "my location" detect it), set your start
(address search, presets, or tap/drag a pin), a distance slider (km/mi), loop vs
one-way, and optional vibe chips (Waterfront / Parks / Landmarks / Neighborhoods)
that bias the picks.

**Route screen** — the assembled route drawn on the map with numbered highlight pins,
total distance / est. run time, a "why this route" rationale (including the roads not
taken), and a "what you'll see" list with a one-line reason for each stop. One-way
routes suggest the nearest transit to ride back from. "Another" re-rolls a different
scenic variation of the same plan.

**Run screen** — live GPS tracking with time / distance / per-unit splits, visual and
spoken turn-by-turn directions, spoken call-outs as you reach each highlight, and
optional ambient narration about the area you're running through (frequency set in
Settings).

### The routing brain (`src/lib/routeBuilder.js`)

- **Loop:** competes several candidate circuits (scenic chains and greedy
  category-diverse picks), routes each through Mapbox, and keeps the one that runs
  through the most scenery with the least backtracking — then trims, grows, or adds a
  measured spur until the real distance lands within 5% of target.
- **One-way:** picks a scenic, transit-friendly *destination* at the right distance,
  threads highlights that lie along the corridor toward it, and tops up with a
  measured mid-route detour.

## Community backend (optional)

`server/index.mjs` is a zero-dependency Node server that turns everyone's saved
runs into shared knowledge: places runners photograph and love get a community
boost in the route builder, the plan screen shows a city's pulse ("312 runs ·
most shot: Brooklyn Bridge Park"), and route highlights show how many runners
photographed them.

- **Run it:** `npm run server` (port 8787; `PORT`/`DATA_FILE` env to override).
  Deployable as-is to any Node 18+ host — no build step, no database to set up.
- **Point the app at it:** set `EXPO_PUBLIC_API_URL` in `.env` (use your LAN IP
  when testing in Expo Go), then `npx expo start -c`.
- **Privacy:** clients send only place ids and run totals — no names, no
  coordinates, no photo pixels. Without the env var the app is fully
  self-contained and learns from your own runs only.

## Theme

iOS-native look: system-style neutral surfaces with a dark evergreen accent, and
Liquid Glass (frosted-blur fallback) on everything floating over the map. Colors
live in `src/theme.js`.

## Extending

- **More cities:** run the pipeline (`pipeline/`) to generate a new
  `src/data/cities/<city>.js` dataset, then register it in `src/data/cities/index.js`.
  The route builder is city-agnostic.
- **Truer Mapbox look / offline tiles:** switch from Expo Go to an Expo dev build and
  add `@rnmapbox/maps`.
